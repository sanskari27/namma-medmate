# WhatsApp module

Outbound messaging channel for Namma MedMate. One platform WABA; chemists do not connect their own number.

## Projects

- UI: `@namma-medmate/whatsapp-ui`
- API: `@namma-medmate/whatsapp-api`
- Docs: this folder

UI talks to the API only through `@namma-medmate/api-client`. Persistence is `@namma-medmate/db-services`.
