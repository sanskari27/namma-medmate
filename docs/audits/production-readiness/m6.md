## complete() money / stock / idempotency

`SalesInvoiceService.complete`: requireReady + lock → COMPLETED replay same key else `DUPLICATE_COMPLETION` → version + expectedTotal + discountReady → `assertFloorStock` → loyalty redeem → allocate → fulfillment `assertCanFill` → `issueForSale` `sale:{invoiceId}:{lineId}` → `chargeForSale` if CREDIT → persist payments → unique V41 → audit + history + snapshot + controlled register.

**Not in TX:** `assertCleared` (P0), `applyOffers` (P0). Client `busy` + reused `completeKey` on failure is correct. Server remains authoritative for totals.
