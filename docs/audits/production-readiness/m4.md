## Findings

### [M4-SKU-001] Empty catalogue recovery sends staff to Purchases, not Add product
- Severity: P1
- Type: UX-FRICTION
- Evidence: Floor empty CTA `navigate(PURCHASES)` “Add stock via purchase.” Catalogue empty copy is a search miss even with zero SKUs.
- Fix: Floor empty CTA “Add product” + secondary purchase. Catalogue: if `products.length===0 && !query` show “No SKUs yet.”

### [M4-RCV-001] Receive / batch / movement UI unmounted; Stock is SKU-only
- Severity: P1
- Type: UX-vs-CONTRACT / DRIFT
- Evidence: Live table = SKU, batch **count**, earliest expiry, MRP. Unmounted receive/detail/movements. Tests still click Receive stock.
- Fix: Row expand: `GET .../batches` + movements. Keep receive hidden if product insists on QC-only inward (document that). Rewrite floor tests.

### [M4-FEFO-001] POS preselects FEFO; warning and FEFO chrome are gone
- Severity: P1
- Type: UX-wrong / TEST-GAP
- Evidence: `buildDraftLine` preselects `suggestedFefo`. Live select has empty “Select batch”; near-expiry is a quiet suffix. Tests still want “Batch (FEFO suggested)” and “Near expiry — still sellable.”
- Fix: Restore banner; label FEFO; drop empty option or block save without a lot.

**Status:** FIXED 2026-09-16 — FEFO option label; near-expiry banner; no empty batch option. `PosScreen.test.tsx`

### [M4-EXP-001] Floor “Expiring ≤ 4 mo” ignores configurable warn days
- Severity: P1
- Evidence: `InventoryOverviewService.EXPIRING_HORIZON_DAYS = 120` vs Guidance `expiryWarnDays` (default 30).
- Fix: Overview near-expiry = `inventory_settings.expiry_warn_days`.

### [M4-ADJ-001] Write-off has no money/stock consequence before send or approve
- Severity: P1
- Evidence: Create copy “quantity stays put.” Server `amountValue` never shown. Approve/Reject immediate; buttons shown to all Inventory users.
- Fix: Confirm qty, direction, cost ₹, new on-hand. Hide Approve unless session user matches rule.

### [M4-TAKE-001] Physical count Start is not OWNER-only in UI
- Severity: P1
- Evidence: Server `requireOwnerStart`. UI Start if `!openTake` — no role check. Tests expect button absent for staff.
- Fix: Hide Start unless `role===pharmacy_owner`. Keep hiding while OPEN exists.

### [M4-TEST-001] InventoryScreen tests target dead floor and omit the live store
- Severity: P1
- Type: TEST-GAP / DRIFT
- Evidence: Test store is **auth only**; live reads `state.inventory`. Mock omits `getInventoryOverview`.
- Fix: Register `inventoryReducer`; rewrite floor tests.
