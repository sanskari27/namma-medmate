# @namma-medmate/shared-ui

shadcn/ui primitives for every app and module. Domain widgets stay under `modules/*/ui`.

- Add components with `pnpm dlx shadcn@latest add {name} --yes -c libs/shared-ui` (skill `shadcn-shared-ui`).
- Import from `@namma-medmate/shared-ui` or `@namma-medmate/shared-ui/components/{name}`.
- Do not copy primitives into apps or module UI packages.
